# Mineral Science Laboratory — Personal Workspace

This repository is the working environment for the computational laboratory
activities of the 
<a href="https://www.unibo.it/en/study/course-units-transferable-skills-moocs/course-unit-catalogue/course-unit/2026/523129" target="_blank">**Mineral Science**</a> 
course.

Create your own **private repository** from this template before the first
laboratory.

```text
course/   material provided by the instructor — do not edit
work/     your personal laboratory work
```

Always work inside `work/`.

At the end of each session:

1. save your files;
2. commit your changes;
3. sync them with GitHub;
4. stop your Codespace.

Course instructions are provided separately through the Mineral Science
Laboratory website.
