# Laboratory 2 — validated reference calculations

This directory contains the validated MgO k-point convergence series
used as fallback data for Laboratory 2.

The series contains matching CRYSTAL input/output pairs for:

```text
SHRINK = 2, 3, 4, 5, 6, 7, 8, 9
```

Students should normally analyse their own calculations. These files are
available when a calculation cannot be completed during the laboratory because
of queueing, maintenance, or another cluster problem.

The reference outputs have been checked against the Laboratory 2 parser.
