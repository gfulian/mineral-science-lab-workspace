# Laboratory 4 — From phonons to thermodynamics

Operational files:

```text
01-gamma-phonons.ipynb
02-qpoint-convergence.ipynb
inputs/
data/
outputs/
reference-results/
```

Create the working copy with:

```bash
update-course
start-lab 04
```

Students calculate:

- Gamma;
- 2x2x2 SCELPHONO.

Instructor reference data provide:

- 3x3x3;
- 4x4x4;
- fallback Gamma and 2x2x2 results.

The input templates deliberately contain:

```text
<A0>
```

for the optimized conventional MgO lattice parameter from Laboratory 3 and:

```text
SHRINK
<X> <X>
```

for the k-point sampling selected in Laboratory 2.

These values are not preselected for the student.
